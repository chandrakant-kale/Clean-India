# 🇮🇳 Clean India

A full-stack waste management platform connecting citizens, collection workers, and business owners through waste collection, verification, and rewards.

### Features
- Three roles: Citizen, Worker, and Business Owner
- OTP-based mobile verification
- Waste collection submission and worker verification
- CI points and wallet rewards
- Coupon creation and redemption
- JWT authentication and bcrypt password hashing

### Tech Stack
**Frontend:** React, Vite, Tailwind CSS, React Router  
**Backend:** Node.js, Express.js  
**Database:** MongoDB, Mongoose  
**Other:** Axios, JWT, bcrypt, Git, GitHub

### Run Locally
```bash
npm install
npm run dev
```

*Note: Run these commands separately in the frontend and backend directories, using each project's configured scripts.*
