# 🇮🇳 Clean India

**Clean India** is a full-stack waste-management platform that connects **citizens, waste-collection workers, and business owners**.

Citizens can submit waste collections, workers can verify them, and citizens can earn **CI points and wallet rewards**. Business owners can create coupons that citizens can redeem using their rewards.

### ✨ Features

* 👤 Citizen, Worker & Owner roles
* 📱 OTP-based registration & authentication
* ♻️ Waste collection submission & verification
* 💰 Wallet & CI points system
* 🎟️ Reward coupons & redemption
* 🔐 JWT authentication & password hashing

### 🛠️ Tech Stack

* **Frontend:** React, React Router, Tailwind CSS, Vite, Axios
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Authentication:** JWT, bcrypt, OTP
* **Tools:** Git, GitHub
